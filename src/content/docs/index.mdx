import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="Keeps your address" icon="email">
    `alice@example.com` stays `alice@example.com`. IDMX changes how mail travels between domains, not who
    you are.
  </Card>
  <Card title="Works with SMTP" icon="random">
    When the recipient's domain does not speak IDMX, the sender uses SMTP as it does today. There is no
    migration date, and no one has to upgrade first.
  </Card>
  <Card title="Authenticated by default" icon="approve-check">
    Every delivery is signed by the sending domain with an HTTP Message Signature (RFC 9421). Keys live in
    DNS, as DKIM keys do.
  </Card>
  <Card title="Built from standard parts" icon="puzzle">
    HTTPS, TLS 1.3, DNS SVCB records, JSON and an OpenAPI contract. No new wire protocol, so you can
    implement it in any language.
  </Card>
</CardGrid>

IDMX is **experimental**. Its first specification draft, v1-draft-00, is in review. See
[Status & roadmap](/status/).
